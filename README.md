# Instructions
1. Install any missing reqs, I had issues with moviepy but ```pip install moviepy==1.0.3``` should work <br>
2. Run the python script <br>
3. Select your mp3 (if there isn't an image associated with it in the metadata then pick your own) <br>
4. Enjoy your mp4! <br>
P.S. I mainly made this because capcut was having issues taking mp3 inputs from my phone...initially anyways then I was bored at 10pm so I made it (with the album art) since scripts for this defintely exist already and I actually used a [stack overflow](https://stackoverflow.com/questions/62634557/using-python-to-get-images-from-an-mp3-file) and [Github repo](https://stackoverflow.com/questions/64375367/python-convert-mp3-to-mp4-with-static-image) that I took inspiration from so I'll reference them below.
